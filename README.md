# Galeria de Conteúdo

Este projeto consiste em uma galeria de imagens interativa e responsiva, organizada por categorias, projetada para exibição de conteúdo visual com suporte a modais (popups) de detalhes e uma interface dinâmica.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias web fundamentais:

* **HTML5**: Estrutura semântica do conteúdo.
* **CSS3**: Estilização do layout, incluindo design responsivo, animações e efeitos visuais (com uso de Flexbox e Media Queries).
* **JavaScript (Vanilla)**: Lógica de exibição da galeria, manipulação de modais, navegação entre imagens e interatividade.
* **Bootstrap**: Utilizado para componentes de layout e suporte estrutural.

## 📂 Estrutura do Projeto

* `index.html`: Arquivo principal que estrutura a interface e os cards de categoria.
* `css/`: Contém o arquivo `style.css` responsável pela aparência e responsividade do site.
* `js/`: Contém o arquivo `script.js` que gerencia os dados da galeria (`galleryData`) e o comportamento dos elementos.
* `assets/`: Pasta contendo as imagens e ícones utilizados no projeto.

## 🛠️ Funcionalidades

* **Grid de Categorias**: Cards responsivos que se adaptam a diferentes tamanhos de tela (mobile-first).
* **Galeria Interativa**: Ao clicar em uma categoria, um modal é aberto exibindo as imagens relacionadas.
* **Navegação**: Suporte para navegação entre imagens (anterior/próximo) via cliques ou teclado.
* **Modo Fullscreen**: Botão para alternar a visualização para tela cheia.
* **Responsividade**: Layout otimizado para dispositivos móveis e desktop.

## 💻 Como Rodar o Projeto

Como este é um projeto estático, não há necessidade de um servidor back-end. Você pode:

1.  Fazer o download ou clonar este repositório.
2.  Abrir o arquivo `index.html` diretamente no seu navegador.
3.  (Alternativamente) Utilizar extensões como o *Live Server* (no VS Code) para visualizar as alterações em tempo real.
